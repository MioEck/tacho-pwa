# Tacho PWA

Progressive Web App fürs Auto: zeigt **Geschwindigkeit (km/h)**, **Höhe (m)**, **Datum** und **Uhrzeit** – in Royalblau mit Milchglas-Design.

- GPS-Geschwindigkeit (mit Fallback-Berechnung, falls das Gerät keine liefert)
- Höhe über GPS
- GPS-Signalstärke (1–4 Balken aus der gemeldeten Genauigkeit; Browser geben keine Satellitenzahl heraus)
- Bildschirm bleibt an (Wake Lock)
- Hoch- und Querformat, offline nutzbar, auf dem Homescreen installierbar

## Nutzung
Über GitHub Pages öffnen, „Tacho starten“ tippen, Standort erlauben.
Installieren: Android/Chrome → Menü → „App installieren“; iPhone/Safari → Teilen → „Zum Home-Bildschirm“.
